## 三、目标受众

| 人群 | 他们的具体问题 | 我们能给什么 |
|---|---|---|
| 内容创作者 | 选题、资料整理、脚本、封面太耗时间 | Agent 实测、工作流、模板 |
| 求职者 | JD 看不懂、岗位真假难辨、简历不会改 | JD 拆解、岗位核实、匹配方法 |
| 职场人 | 重复工作多、AI 工具不会用 | 具体任务的前后对比 |
| 程序员 | 想看真实搭建，不想看概念 | 真实录屏、成本、翻车 |

## 四、内容支柱

| 支柱 | 占比建议 | 例子 |
|---|---:|---|
| Agent + 求职 | 40% | JD 避坑、岗位真假、简历匹配、面试追问 |
| Agent 实测 | 40% | 资料整理、信息监控、内容采集、会议纪要 |
| Agent 认知 | 20% | 概念、5 个部件、工具边界、常见误区 |

先做“求职”切口，不等于只做求职。  
它只是更容易被搜索、被收藏、被评论的入口。

## 五、发布节奏

建议先按“每周 2 条”跑：

- 周二：一条“判断/避坑/实测”；
- 周六：一条“方法/教程/复盘”；
- 每周至少回复评论区 2 次；
- 每月做一次数据复盘（收藏、评论、私信）。

不要一开始日更。  
先用 4 周验证：能不能稳定产出、有没有人收藏、有没有人问“怎么做”。

---

## 六、内容视觉与形式

- 封面：高对比大字 + 前后对比/真实截图；
- 形式：录屏 + 字幕，不强制露脸；
- 时长：30～60 秒；教程可 90 秒；
- 标题：具体任务 + 结果/判断，不写“AI 时代必看”；
- 主页：昵称、头像、简介、置顶笔记保持一致。

---

## 七、指标

先看四个：

1. 收藏：有没有“以后用”的价值；
2. 评论：有没有人问“怎么做/能不能帮我做”；
3. 搜索流量：有没有长期被搜到；
4. 私信：有没有真实需求。

不要只看点赞。
