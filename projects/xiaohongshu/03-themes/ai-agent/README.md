## 一、这个专题怎么使用

AI Agent 相关资料保留，是因为它可能帮助解决一些真实任务。但账号不以 Agent 技术本身为内容中心。

如果未来分享 Agent，应该先讲它能帮用户做什么、实际效果怎么样，再按需要解释背后的实现。用户不需要为了看懂内容先学习 Agent 架构、工具调用、MCP 或工作流。

## 二、目前已有的具体应用：AI 求职

求职是一个具体场景：需要从大量招聘信息中找到值得关注的岗位，再整理要求、分析匹配度。

AI Agent 或其他 AI 工具可能参与其中，但内容要回答的是：
- 是否减少了逐条浏览的重复劳动？
- 收集的信息是否足够准确、及时？
- 分析结果能不能帮助求职者做决定？
- 有哪些地方仍然必须人工核验？

它只是一个应用案例，不意味着账号变成 AI 求职号。

## 四、内容表达边界

- 不为了展示 Agent 技术而做技术科普；
- 不把“模型执行了流程”直接说成“用户问题解决了”；
- 不夸大自动化程度、准确率或效率；
- 不隐藏人工核验、成本和失败情况；
- 技术术语只有在读者理解实际效果确实需要时才解释。
