## 记录规则

每条发布内容建立一条记录，至少保留：

- 笔记 ID、标题、主题和对应选题；
- 发布日期、笔记链接、内容形式；
- 封面版本和正文/视频版本；
- 曝光、阅读/播放、点赞、收藏、评论、分享、主页访问、关注（以平台实际提供的数据为准）；
- 搜索来源或关键词（如平台提供）；
- 评论区高频问题、用户原话和后续选题；
- 复盘结论：继续、调整、停止。

不为了凑指标填写不存在的数据。无法查看的字段写“未提供/未记录”。

## 首轮复盘原则

- 不用单篇数据判断整个账号定位；
- 先发布 6～8 条，再比较三条内容线；
- 关注收藏、评论、主页访问/关注、搜索和制作成本，不只看点赞；
- 每次复盘尽量只调整一个主要变量。
