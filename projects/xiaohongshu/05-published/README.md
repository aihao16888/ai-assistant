## 记录原则

每条已经发布的笔记可以记录：

- 标题、发布日期、笔记链接和内容形式；
- 对应的真实场景或案例；
- 封面/正文素材版本（便于追溯，不代表必须使用统一模板）；
- 曝光、阅读/播放、点赞、收藏、评论、分享、主页访问和关注（以平台实际提供的数据为准）；
- 评论区值得关注的问题和用户反馈；
- 发布后的观察和下一步想法。

不为了凑指标填写不存在的数据。无法查看的字段写“未提供/未记录”。

## 复盘原则

- 不用单篇数据判断整个账号定位；
- 结合内容题材理解收藏、评论、搜索和关注等信号；
- 不为了追求某个指标而牺牲内容真实性；
- 根据真实反馈决定是否继续，不预设必须做成系列。
