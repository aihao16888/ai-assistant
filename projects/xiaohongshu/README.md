## 四、内容主线

**主线：AI 实践探索。** 按真实任务组织内容，不按工具目录组织内容。

- 今天拿 AI 做了什么；
- 我把一个想法做出来；
- 这次折腾翻车了。

AI Agent、AI 求职、AI Coding 等保留为专题。当前 `03-themes/ai-agent/` 中的 JD 避坑和简历内容是专题候选，不代表账号整体定位，也不默认作为首发内容。

## 五、从素材到发布的链路

```text
02-sources：采集真实需求和对标笔记
  ↓
03-themes：提炼自己的内容角度，进入选题池
  ↓
04-series：选题 → brief → 脚本/正文 → 封面 → 录屏/截图
  ↓
05-published：发布链接 → 数据 → 评论反馈 → 复盘
  ↓
06-assets：沉淀可复用模板和素材
```

### 内容准入规则

1. 选题必须对应一个具体人群和具体任务；
2. 对标只学习问题、结构和表达，不搬运文案/图片；
3. 笔记必须基于本人真实操作或已完成的可复现实验；
4. 结论必须有截图、录屏、输出或其他证据支持；
5. 必须记录失败点、限制或人工修正；
6. AI 生成/润色内容按平台当前要求声明；发布和互动由真人负责。
