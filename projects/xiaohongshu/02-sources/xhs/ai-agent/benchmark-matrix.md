# 小红书对标矩阵：AI Agent × 内容/求职

- 日期：2026-11-25
- 关联任务：为「AI Agent 内容」找 20 条对标笔记，拆选题、封面、标题、结构、评论区
- 数据表：[benchmark-matrix.csv](benchmark-matrix.csv)
- 深拆报告：[benchmark-deep-dive.md](benchmark-deep-dive.md)
- 适用方向：AI Agent / 智能体 / AI 求职 / JD 分析

> 结论先说：**已用 OpenCLI 只读采集 20 条首轮候选，并填入 CSV。**
> 采集时间：2026-11-25；点赞为搜索页显示，粉丝/收藏/评论/封面/结构等字段需要逐条深拆。
> 全程只读：未点赞、未关注、未私信、未批量抓取。

---

## 一、20 条怎么分配

不要随便搜 20 条。按 4 组关键词，每组 5 条，正好 20 条：

| 组 | 关键词 | 看什么 |
|---|---|---|
| A | `AI Agent`、`智能体`、`Agent 是什么` | 用户对 Agent 的认知、概念类内容 |
| B | `AI Agent 实测`、`Agent 工作流`、`智能体 搭建` | 真实搭建、实测、工作流 |
| C | `AI 求职`、`AI 简历`、`AI 面试` | AI 如何用于求职 |
| D | `JD 分析`、`Boss直聘`、`岗位分析` | 岗位描述、招聘数据、信息差 |

每组 5 条，能同时覆盖「概念、实操、求职、数据」四个方向，不会全是同一种内容。

---

## 二、怎么筛选：不要选大号

优先选：

- 粉丝 **1 万以下**；
- 互动 **500+**；
- 近 **3 个月**内发布；
- 评论区有人问「求教程」「求模板」「求方法」「求链接」；
- 你能用 Agent + 公开数据做出来。

不要优先选：

- 几十万粉的大号；
- 只有观点、没有过程的内容；
- 纯工具广告；
- 你完全无法复现的内容。

---

## 三、20 行怎么填（首轮已填，待深拆列）

打开 [benchmark-matrix.csv](benchmark-matrix.csv)，首轮已填链接、作者、点赞、发布时间、选题、标题句式；标“待深拆/待补”的列需要逐条打开补。

| 列 | 填什么 |
|---|---|
| 关键词组 | 已预填 A/B/C/D 四组 |
| 笔记链接 | 小红书笔记 URL |
| 作者 | 昵称 |
| 粉丝量 | 主页显示 |
| 点赞/收藏/评论 | 笔记数据 |

| 选题 | 这条笔记到底讲什么，一句话 |
| 封面类型 | 大字/对比/截图/人物/表格 |

| 开头钩子 | 前 3 秒/前 3 行怎么抓人 |
| 内容结构 | 痛点→方法→结果/清单/对比/故事 |
| 评论区高频问题 | 用户反复问什么 |
| 可复用点 | 你能学哪一个动作 |
| 我能否做 | 能/不能/需要什么 |
| 备注 | 数据待补、疑似广告等 |

## 四、手动找的步骤

1. 打开小红书搜索；
2. 输入 A 组关键词；
3. 筛选「最多点赞」+「图文/视频」；
4. 找 5 条粉丝 1 万以下、互动 500+、近 3 个月的；
5. 点进主页确认粉丝量；
6. 记录链接、数据、选题、封面、标题、结构、评论区；
7. 换 B/C/D 组，重复；
8. 20 行填满后，先别写标题，先找规律。

## 六、首轮采集说明

已采集 4 组 × 5 条，共 20 条，填入 CSV。

| 组 | 采集结果 | 备注 |
|---|---|---|
| A | 概念、趋势、开源、普通人痛点、面试 | 高赞概念类偏多 |
| B | 教学智能体、0 代码、教育复盘、手搓、周末搭建 | 实操教程偏多 |
| C | 自动投简历、高薪方法、HR 视角、AI 求职方法、体验 | 自动投递类谨慎参考 |
| D | JD 避坑、AI+HR、京东真题、AI 拆 JD、分析岗趋势 | 数据/岗位分析偏多 |

**注意：**

- 点赞数是搜索页显示值，可能不是实时；
- 粉丝、收藏、评论、封面类型、内容结构、评论区问题还没有逐条打开，标为“待深拆”；
- 链接带 `xsec_token`，可能过期；过期后按同一关键词重新搜索；
- C 组“Codex 自动投简历 Skill”属于自动投递方向，只作为对标，不作为推荐做法。

建议先深拆 4 条，一组一条：

- A1：`20分钟全面拆解到底什么是 AI 智能体`
- B2：`Howto小白从0到1搭建AI Agent｜0代码`
- C3：`招聘邪修：AI帮我找工作，亲测有效`

## 七、填完怎么用

20 行填完后，不要直接写标题。先做三件事：

1. **找 3 个重复出现的选题**：说明这类内容被验证过；
2. **找 3 个评论区反复问、但没人讲透的问题**：这是空白；
3. **找 3 个你能用 Agent + 公开数据做出来的角度**：这是你的差异化。

最后才写标题。  
标题不是起点，选题和证据才是。

## 八、下一步

A1、B2、C3、D1 已完成深拆，详见 [benchmark-deep-dive.md](benchmark-deep-dive.md)。

下一步不建议继续堆 20 条，而是：

1. 从 4 条深拆里选 1 个可复用结构；
2. 用你自己的真实 JD/经历跑一遍；
3. 先写第一条“JD 能不能投”或“AI 帮我找工作”的内容；
4. 发布后看收藏和评论，再决定是否系列化。

这样比“再看 100 条”更有效。
