## 二、A1：20 分钟拆解 AI 智能体

### 数据

- 点赞：3.2 万
- 收藏：3.2 万
- 评论：656
- 类型：真人出镜长视频

### 封面

- 真人出镜，房间背景；
- 黑色边框 + 大字字幕；
- 文案：“找到可以借鉴和使用的方法”“视频很长”；
- 不是精美设计，而是“真人 + 大字 + 信息量”。

### 开头钩子

> “Agent 绝对是这两年最值得你去投入的技能之一。但如果你对他还是一知半解，有点模糊的话……”

先给判断，再指出“你可能没懂”，制造继续看的理由。

### 内容结构

20 分钟长视频，拆成 6 段（1 个区别 + 5 个核心部件），并给出时间戳：

1. Chat 和 Agent 的区别
2. Context（上下文）
3. Memory（记忆）
4. Skill（技能）
5. Tools（工具）
6. 文件结构（Folder Structure）

还加了一句：

> “我不建议你一次性看完，但绝对值得你收藏。”

这句话很关键：它把“看不完”变成“先收藏”，直接提高收藏率。

### 评论区在问什么

- “有 Codex、Claude Code 了，为什么还要自己搭 Agent？”
- “普通用户还没开始回答，token 就用完了。”
- “两台电脑登录 WB 是同一个环境吗？”
- “五部分拆得很清楚，先收藏慢慢啃。”

### 可复用点

- 长视频 + 时间戳 + 收藏导向；
- 先给判断，再拆概念；
- 用“你可能没懂”制造继续看的理由；
- 评论区问题就是下一条选题。

### 你能不能做

能，但门槛高：

- 需要真的理解 Agent；
- 需要 20 分钟的内容密度；
- 需要真人出镜/口播。

**不建议作为第一条。**

## 三、B2：0 代码搭建 AI Agent

### 数据

- 点赞：918
- 收藏：1105
- 评论：16
- 类型：真人出镜 + 竖屏 + 屏幕录制

### 封面

- 真人出镜，室内背景；
- 下方是 ChatGPT/搭建界面录屏；
- 左侧大字：“小白 搭建专……”；
- 字幕：“这个还是程序员的事”。

### 开头钩子

> “从 0 到 1 搭建一个 AI Agent，全程没写一行代码，从零到能用，也就十几分钟。”

三个关键词：**0 代码、十几分钟、手把手**。

### 内容结构

视频教程，用一个具体案例：

> 小红书爆款文案助手。

评论区有人总结了她的框架：

> 角色、目标、工具、规则、输出格式。

这就是一条“低门槛教程”的标准结构：

1. 具体案例；
2. 角色设定；
3. 目标；
4. 工具；
5. 规则；
6. 输出格式。

### 评论区在问什么

- “适合我这种不懂代码、不懂专业名词的小白。”
- “角色、目标、工具、规则、输出格式。”
- “小红书不推 AI 生成的内容，一定要搭配真人及现实照片才会有流量。”
- “ChatGPT 顶级会员一个月 20 刀都不够。”

### 可复用点

- 低门槛 + 具体案例 + 可跟做步骤；
- 真人出镜增加信任；
- 评论区直接给出“框架总结”，可以拿来做下一条。

### 你能不能做

能，但需要：

- 真人出镜或至少真实录屏；
- 一个能跑通的案例；
- 不造假、不跳步骤。

**如果你不想露脸，这条不是最优起点。**

## 四、C3：招聘邪修，AI 帮我找工作

### 数据

- 点赞：1199
- 收藏：1739
- 评论：60
- 类型：图文/纯文字封面

### 封面

- 米白色背景；
- 顶部红色小字：“17 年国企 HR·亲测”；
- 中间黑色超大字体：

> 找工作  
> 别自己刷  
> 招聘软件了

- 底部作者名。

封面没有图，只有**身份 + 反常识 + 大字**。

### 开头钩子

> “找工作别自己一个个刷软件了，把简历发给 AI，让它替你干。”

一句话同时有：

- 身份：干招聘的；
- 反常识：别自己刷；
- 结果：让 AI 替你干。

### 内容结构

三步：

1. **简历匹配**：把脱敏后的简历发给 AI，让它去招聘网站匹配岗位；
2. **核实岗位**：让 AI 查岗位是否还在招、什么时候发布、招聘者活跃度；
3. **打包处理**：分梯队、改简历、准备降薪谈判、输出报告、脱敏。

最狠的一句洞察：

> “很多岗位挂在那儿，其实早就不招了，你投一百份也是石沉大海——不是你不行，是那个坑根本不存在。”

这句话就是整篇的“钉子”。

### 评论区在问什么

- “先用 AI 筛选，最后一步手动投简历吗？”作者确认：对，招聘网站要登录才能投。
- “我两个月前就这样做过了，没用。”
- “AI 推荐了一个工作，但网址已经荒废十多年，不能完全依赖。”
- “好心人不要删，等我过两天找工作用一下。”

### 可复用点

- 身份 + 亲测 + 三步 + 一个狠洞察；
- 纯文字大字封面，成本极低；
- 评论区就是需求验证：有人问“手动投吗”，有人求别删。

### 你能不能做

能，而且这是 **C 组最值得参考的一条**。

但注意：

- 不要冒充“17 年 HR”；
- 不要做“自动投递”；
- 必须真实跑一遍，不能编“我帮 100 个人找到工作”。

## 五、D1：这个 JD 能投吗？

### 数据

- 点赞：5184
- 收藏：4152
- 评论：19
- 类型：视频 + 手写白板

### 封面

- 视频画面：手写白板/笔记；
- 红色大字：“小红书首届 JD 锐评大赛 互联网行业话事人”；
- 下方字幕：“我是作为小红书首届 JD 锐评大赛……”
- 不是精修图，是“真实手写 + 活动背书 + 大字”。

### 开头钩子

> “这个 JD 能投吗？从岗位介绍就能看出是不是坑。”

疑问句 + 避坑 + 具体对象，三个元素都很强。

### 内容结构

- 视频手写拆解 JD；
- 置顶评论邀请大家留 JD；
- 评论区直接变成“奇葩 JD 共赏”；
- 作者在评论区继续收集案例。

这不是“讲完就结束”，而是**用评论区继续生产内容**。

### 评论区在问什么

- “五险一金不是福利，是法律规定必须要缴纳的。”
- “真的有很多公司没有公积金，甚至试用期社保都没有。”
- “这种 JD 鉴坑技能真的很实用，尤其是 AI 岗，写得越花哨越要警惕。”
- “真正靠谱的团队 JD 反而写得克制具体。”

### 可复用点

- 疑问句 + 避坑 + 互动征集；
- 评论区就是选题库；
- 真实 JD 案例 + 手写拆解，信任感强；
- 收藏/点赞 ≈ 0.8，强收藏。

### 你能不能做

能，但需要：

- 真实 JD 案例（脱敏）；
- 一套判断框架；
- 愿意在评论区接案例。

**这是最适合你“Agent + JD”想法的参考。**

## 六、4 条放在一起，说明什么

### 1. 收藏 > 点赞，说明“工具书”比“热闹”更值钱

- A1：收藏 = 点赞；
- B2：收藏 > 点赞；
- C3：收藏 > 点赞；
- D1：收藏接近点赞。

用户存下来，是为了“以后用”。  
所以内容要有**可执行步骤、判断标准、模板、清单**。

### 2. 封面不需要精美，需要“高对比 + 一句话”

- A1：真人 + 黑框 + 大字；
- B2：真人 + 录屏 + 大字；
- C3：纯文字 + 超大黑字；
- D1：手写白板 + 红色大字。

四种封面，没有一种是“精修海报”。

### 3. 开头不是自我介绍，是“判断/反常识/结果”

- A1：Agent 是值得投入的技能，但你可能没懂；
- B2：0 代码、十几分钟、手把手；
- C3：别自己刷招聘软件了；
- D1：这个 JD 能投吗？

### 4. 结构要“可跟做”

- A1：5 部分 + 时间戳；
- B2：角色/目标/工具/规则/输出；
- C3：3 步；
- D1：手写拆 JD + 评论区征集。

### 5. 评论区是下一条内容

- A1：为什么还要自己搭 Agent？
- B2：小红书不推 AI 生成内容，要真人/真实照片；
- C3：先 AI 筛选再手动投？
- D1：更多奇葩 JD。

## 七、对你“Agent + JD”想法的判断

你的想法是：

> 用 DeepSeek Harness + OpenCLI 拉 Boss直聘/官网 JD，做岗位分析。

这可以做，但**不要直接做成“数据分析报告”**。

从这 4 条看，最容易起量的包装是：

### 方向 1：JD 避坑

> “这个 JD 能投吗？我让 Agent 拆了它的隐藏要求。”

- 参考 D1；
- 先讲判断，再讲 Agent；
- 用真实 JD，脱敏；
- 评论区收集下一个 JD。

### 方向 2：AI 求职亲测

> “我用 Agent 把简历和 JD 对了一遍，发现很多岗位挂着但不招。”

- 参考 C3；
- 身份要真实：你是程序员，不是 17 年 HR；
- 讲 3 步：匹配 → 核实 → 分梯队；
- 强调人工确认，不自动投递。

### 方向 3：招聘信息差

> “同一家公司，Boss直聘和官网的 JD，差在哪？”

- 这是你的差异化；
- 需要找同一岗位的两份来源；
- 输出差异表；
- 比“我分析了 50 个 JD”更有信息差。

**不要先做：**

- “我用 Agent 分析了 100 个 JD”这种大报告；
- “Agent 自动投简历”（平台/诚信风险）；
- “0 代码搭建 Agent”教程（B2 已经很强，且需要真人出镜）。

## 八、建议的第一条

不是“Agent 教程”，也不是“大报告”。

建议：

> **“这个 JD 能投吗？我让 Agent 拆了它的 3 个隐藏信号。”**

结构：

1. 拿一个真实 JD（脱敏）；
2. 先给判断：能投/谨慎/别投；
3. 用 Agent 拆 3 个信号：职责模糊、年限/薪资不匹配、隐性加班/外包；
4. 给出“怎么改简历/怎么问 HR”的一句话；
5. 结尾：评论区留 JD，下期拆。

这条同时借了 D1 的“避坑”和 C3 的“亲测”，但用的是你自己的程序员身份，不需要装 HR。
