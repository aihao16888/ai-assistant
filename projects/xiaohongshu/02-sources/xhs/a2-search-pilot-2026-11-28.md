## 候补选题的实测提案

用 2～3 份公开 PDF 准备三道有人工底稿的问题。第一道在单页就能找到答案，第二道需要跨页或跨文件，第三道资料没有交代。用同一工具分别直接提问、再明确要求带出处。逐项核对答案、文件名、PDF 实际页码和原句，并检查第三题能否明确说找不到。短笔记可以只展示最容易看出差异的一组结果。

样本来自同一账号可见的两组综合搜索，评论为有限抽样。用户对工具的评价和帖子自述效果仍待验证。互动数为采集时点的快照，空白字段为未取得。记录使用去除临时参数的笔记链接，必要时可用原标题重新搜索。评论只保留匿名摘要。

## 沉淀的脚本

本轮沿用 OpenCLI 小红书适配器作为复跑入口。两条命令都已跑通。

```sh
OPENCLI_CLOSE_OWNED_TAB=1 opencli xiaohongshu search 'AI 找 PDF 原文' --limit 10 --sort comprehensive --window background --site-session ephemeral -f json
OPENCLI_CLOSE_OWNED_TAB=1 opencli xiaohongshu search 'PDF 问答 引用页码' --limit 10 --sort comprehensive --window background --site-session ephemeral -f json
```

按笔记 ID 去重后，用当次搜索返回的完整 URL 运行 `xiaohongshu note` 和 `xiaohongshu comments --limit 10`，在 Chrome 后台使用临时会话。
