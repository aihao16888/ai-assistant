# 面试问题库

## 问题分类

- Java 基础：集合、异常、泛型、JVM、并发、线程池；
- Spring：IOC、AOP、事务、自动配置；
- Redis：缓存、防重、分布式锁、原子计数、一致性；
- 数据库：索引、SQL 优化、事务、锁、隔离级别；
- 消息中间件：生产消费、路由、ACK、重试、幂等和消息积压；
- 分布式系统：多实例、负载均衡、服务治理、数据一致性；
- 工程运维：Linux、Git、日志、监控和单元测试；
- 项目场景：围绕本人实际参与的业务提出问题。

## 每道题需要记录

- 问题原文或准确概括；
- 来源类型：真实面试 / JD 推断 / 自主练习；
- 关联公司和岗位（如有）；
- 对应知识专题和项目故事；
- 参考答案；
- 常见追问；
- 自己当前能否独立回答。

不要把模拟问题标记成真实面试问题。公司专项中的问题可以先保留在对应 applications 目录，后续确认具有跨公司复用价值后再抽取到这里。
