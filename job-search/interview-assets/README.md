# 通用面试表达素材

这里存放跨公司可复用的项目故事、问题和回答框架。它与岗位专项准备的区别是：本目录沉淀长期可复用的表达资产，applications 只记录某家公司本轮选用哪些故事和问题。

## 子目录

- [story-bank/](./story-bank/README.md)：将真实项目经历整理成可讲述、可追问的故事。
- [question-bank/](./question-bank/README.md)：归档通用技术问题、项目场景问题和真实面试问题。
- [answer-frameworks/](./answer-frameworks/README.md)：沉淀项目介绍、技术问题和故障排查的回答结构。

## 质量要求

- 故事必须来自 profile 中的真实项目素材。
- 问题必须标记来源：真实面试、岗位 JD 推断或自主练习。
- 回答框架用于组织表达，不得替代真实事实和技术证据。
