# 待整理信息收集箱

这里仅用于临时收集尚未整理的招聘和面试信息，不作为长期归档位置。

## 收集时至少记录

- 收集日期；
- 公司与岗位名称（未知时注明未知）；
- 信息来源或原始链接；
- 招聘原文、面试问题或用户自己的记录；
- 信息是否完整、是否需要核实。

## 归档规则

- 招聘要求和公司公开信息整理到 companies/。
- 个人项目和经历补充到 profile/。
- 某家公司对应的准备、简历版本和面试复盘整理到 applications/。
- 可复用的技术知识整理到 knowledge/。
- 可复用的项目故事和回答框架整理到 interview-assets/。

整理完成后删除 inbox 中的临时副本或将其标记为已归档，避免同一资料出现多个事实来源。
