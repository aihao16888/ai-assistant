## 5. 岗位能力画像（分析推断，不是招聘原文）

根据职责与要求，岗位可能重点考察以下能力：

1. **Java 后端基础**：集合、异常、泛型、JVM、并发编程、线程池、Spring 体系和接口设计。
2. **数据库能力**：索引、执行计划、事务隔离、锁、慢 SQL 定位、数据一致性。
3. **Redis 实战**：缓存设计、缓存一致性、分布式锁、原子操作、缓存穿透/击穿/雪崩。
4. **消息队列**：消息投递、确认、重复消费、失败重试、死信队列、消费幂等。
5. **分布式与微服务**：多实例部署、服务间调用、超时重试、负载均衡、故障隔离和数据一致性。
6. **工程与线上排障**：Linux 日志排查、Git 协作、单元测试、监控告警、性能分析。
7. **系统设计与交付**：能够从业务问题出发说明方案、边界、异常处理和落地过程。

这些是基于 JD 的合理准备方向，不代表已经知道诺因智能实际采用的技术架构，也不代表面试官一定会逐项提问。
