## 3. 不同表达等级

简历和面试中应区分：

- **实际负责并实现**：本人直接设计或编写了相关代码，可以讲清楚实现和问题。
- **参与开发或维护**：参与了部分模块，明确说清负责范围。
- **实际使用但理解不深入**：可以说项目使用过，但不要声称精通。
- **理论学习或个人实验**：可以说学习或实践过，但不能归入生产项目经验。
- **未实践**：不写成掌握或项目经验。

## 4. 针对诺因智能的初步差距

- Java：匹配主语言要求，重点补并发、线程池和 JVM。
- MySQL/PostgreSQL：需要准备 SQL 优化、索引、执行计划和事务。
- Redis：有真实业务场景，但需要深入锁失效、原子递增和缓存一致性。
- RabbitMQ：有真实消息同步场景，但需要补消息可靠性与消费幂等。
- Linux/Git：有实际接触，需要补完整、可复述的操作案例。
- 微服务/分布式：有多服务器系统背景，但拓扑和一致性机制待核实。
- Docker/Kubernetes/MongoDB/Kafka：当前不作为实际项目经验；按岗位要求补基础认知。
