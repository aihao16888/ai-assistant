# 个人经历与简历事实库

> 本目录是所有岗位定制简历和项目故事的事实来源。公司专项材料可以选择和调整表达，但不能反向改变这里记录的真实经历。

## 当前素材

- [主简历事实底稿](./master-resume.md)：汇总工作经历、教育背景、技能和项目经历；目前尚待用户补充和核实。
- [DMS 完整项目素材](./projects/document-management-system.md)：记录业务背景、本人参与范围、技术场景和待补证据。
- [简历项目经历素材库](./resume-projects/README.md)：将完整项目素材提炼成可直接复制进简历的 4–5 条短描述，与项目故事分开维护。
- [DMS 简历项目经历](./resume-projects/document-management-system.md)：当前 DMS 项目的简历表达初稿及故事映射。
- [个人技术栈与实践边界盘点](./skills-inventory.md)：区分实际使用、参与维护、理论学习和未实践技术。

## 维护原则

1. 只记录本人真实参与的工作；团队整体能力不能自动算作个人能力。
2. 项目职责尽量写清楚“本人负责、本人参与、协助排查、仅了解”的边界。
3. 不编造项目规模、QPS、耗时、性能提升比例、故障结果或技术方案。
4. 每个重要项目故事应能回到项目素材和证据。
5. 简历项目经历只保留招聘方需要快速看到的贡献，不在简历中堆叠完整技术解释。
6. 岗位定制简历存放在对应 applications 目录，不覆盖主简历事实底稿。
