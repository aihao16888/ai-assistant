## 2. 进一步判断

- “已匹配”只表示经历方向符合，不表示已经达到招聘方所说的熟练或精通。
- “部分匹配”需要通过项目职责、技术原理和可核验证据进一步证明。
- “待确认”不能在简历中写成已掌握或独立负责。
- Docker、Kubernetes、MongoDB 等没有确认的生产实践，不能包装为项目经验。
