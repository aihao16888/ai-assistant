# 公司与岗位专项准备

每家公司、每个岗位建立独立目录。这里保存的是“如何针对这个岗位准备”，不是个人经历的唯一事实来源，也不是通用技术知识库。

## 每个岗位目录建议包含

- README.md：本轮准备入口、状态和主要链接。
- jd-match-analysis.md：逐项对照岗位要求和个人经历。
- project-experience-adjustment.md：确定哪些项目故事和职责应突出，记录待核实事实。
- resume-version.md：保存本岗位的简历版本及版本说明。
- preparation-plan.md：复习顺序、模拟题、待补事实和行动计划。
- interview-reviews/：记录每轮面试的实际问题、追问和复盘。

## 维护规则

1. 专项目录引用 companies、profile、knowledge 和 interview-assets，不复制整份原文。
2. 简历版本必须能追溯到 profile 中的真实事实。
3. 招聘要求、分析推断和真实面试反馈必须区分。
4. 面试结束后尽快记录原始问题和回答情况，再整理成可复用知识。
