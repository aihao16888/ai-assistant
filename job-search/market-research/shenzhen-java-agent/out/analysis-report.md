## 三、Java 后端常见要求

基于 25 份 Java / 后端标题命中岗位详情，统计正文或技能标签中出现过的关键词：

| 要求关键词 | 出现岗位数 | 覆盖率 |
|---|---:|---:|
| Java | 16 | 64% |
| MySQL | 19 | 76% |
| Redis | 13 | 52% |

| Spring Boot | 14 | 56% |

**分析判断：** Java、关系型数据库、缓存、消息队列和微服务是当前样本里最稳的后端底座。容器部署出现频率较低，但仍是值得补齐的工程能力。这个统计是“文本出现”，不等于每条岗位都把它列为硬性要求。

## 五、个人准备建议

优先级是从当前岗位样本推出来的学习顺序，不代表已确认的个人掌握状态。

- **P0：Java 后端底座。** Java、Spring Boot/Cloud、MySQL、Redis、消息队列、微服务和接口设计；练习把并发、幂等、事务、缓存一致性和故障处理讲清楚。
- **P1：AI 应用工程。** Python 服务开发、模型 API 集成、结构化输出、工具调用、Agent 状态/工作流、RAG 检索与向量库、效果评测、日志和部署。
- **P2：按岗位补专项。** 多模态/算法训练、金融风控、支付、电商或硬件领域知识，只有投递相应岗位时再深入。
- **可验证的练习项目：** 做一个能展示后端工程能力的 Agent 应用：Java 服务提供业务 API，Python/Agent 编排完成工具调用与 RAG，加入测试集评测、超时重试、日志和容器部署。所有简历描述必须回到本人实际完成的功能和证据。
