## 调研范围

- 地区：深圳。
- 岗位：Java 后端；以及与 Java 后端经验相关的 AI Agent、LLM 应用和 RAG 应用开发。
- 薪资：月薪下限至少 20,000 元。薪资面议或范围无法确认的职位进入待核实项。
- 排除项：外包公司和猎头岗位；名称命中只作为线索，最终排除需核对招聘主体和用工关系。

## OpenCLI 空白标签问题与待办

### 根因与证据

- 根因已由真实 Chrome 页签、扩展/CLI 版本和 CLI session inventory 交叉确认：旧版 1.8.7/扩展 1.0.33 在最后一个 automation lease 释放时留下 `about:blank` 占位页；并发 ephemeral 会话会让它更频繁出现。
- 采集器还有一条独立放大路径：外层 60 秒定时器向 OpenCLI 发 SIGTERM，绕过 OpenCLI 的 lease/tab 清理。两个采集脚本现设置 `OPENCLI_BROWSER_COMMAND_TIMEOUT=180`，移除了外层强杀，并在子进程设置 `OPENCLI_CLOSE_OWNED_TAB=1`。
- 批次运行时，新建的 adapter 标签在首次导航前可能短暂显示 `about:blank`；这只是加载中的起始页。必须等采集进程退出再判断是否残留。最终 27 条队列运行完、采集进程退出后检查 Chrome，全局标签清单无空白页；这是当前链路的实际采集验证。
- 详情漏采是另一条独立根因：BOSS adapter 的 DOM 解析器未识别多种页面结构。HTTP 200 的保留 HTML 中含有真实职责、要求和公司字段，但 adapter 将部分响应报成 `AUTH_REQUIRED` 或“不完整职位”；新增本地 HTML 解析回退与离线恢复工具后已恢复。
- 其中两种页面形态已解析：完整职责/要求文本；只给短摘要的页面。后者标记为 `short-summary`，不补造任职要求。解析器不会保留招聘者姓名或联系方式。

### 可证伪假设

1. 上游扩展的最后租约释放会把标签页导航到 `about:blank`。预测：使用上游版本打开并关闭一个新会话会留下空白占位；修复版在借用的用户窗口关闭该标签页。
2. ephemeral 会话/并发放大残留数量。预测：并发越高空白标签越多，复用单个持久会话则减少；此假设只能解释频率，不能解释单个会话为何留下空白。
3. 守护进程租约状态不一致导致孤儿页。预测：如果是主因，清零租约并更换扩展后仍会持续出现；如修复后不再产生，则该假设降级。

## 后续采集与分析

1. 岗位硬条件：深圳、薪资下限、招聘主体、岗位是否仍有效。
