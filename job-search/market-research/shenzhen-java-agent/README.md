# 深圳 Java 后端与 AI Agent 岗位调研

> 调研日期：2026-11-26 至 2026-11-27  
> 关联工作区：[`job-search`](../../README.md)  
> 当前状态：列表采集已遍历 18 个关键词/薪资组合中的 17 个；有 1 个组合页在两次 60 秒冷却重试后仍未返回职位列表。按最新筛选（整段月薪 20–40K、经验区间上限不超过 5 年）及外包/猎头规则去重后，当前目标索引为 81 个岗位、68 个列表公司名；63 个有详情正文，18 个详情未完成。

## 调研范围

- 地区：深圳。
- 岗位：Java 后端；以及与 Java 后端经验相关的 AI Agent、LLM 应用和 RAG 应用开发。
- 薪资：职位标示的整段月薪区间必须完整落在 20,000–40,000 元内；区间上限超过 40,000 元或无法解析的记录不进入岗位索引和详情采集队列。
- 经验：职位标示的经验区间上限不得超过 5 年；例如“5–10 年”“5 年以上”均排除，“3–5 年”保留。
- OpenCLI 当前 BOSS 搜索只提供离散薪资档（含 20–30K、30–50K），没有 30–40K 档。为覆盖 30–40K 职位，仍需查询 30–50K 档；超出 40K 的结果在本地收到列表响应后立即过滤，不写入岗位数据、不请求详情。
- 排除项：明确公司名/职位名命中德科、猎头、外包、人力资源服务、劳务派遣或人才服务的岗位；“客户公司”关系或服务许可证单独出现时只列待核验，不直接判作外包。

## 目录约定

- `raw/`：保存 OpenCLI 原始搜索响应，不覆盖原始记录。
- `out/`：保存去重后的岗位表、企业筛选结果和分析报告。
- 原始页面明确写出的信息与 AI 推断分开，分析项保留对应来源链接和判断依据。
- 经人工核验并值得跟进的公司/岗位，再归档到 `job-search/companies/`；投递准备放入 `job-search/applications/`。

## 去重与幂等性

- 职位唯一键优先使用 BOSS `security_id`；缺失时使用去掉查询参数和片段的职位 URL；两者都缺失才回退到公司、职位、薪资和区域组合。
- 搜索原始 JSONL 保留各关键词/薪资档/页码的命中证据；岗位 CSV 是按唯一键合并后的当前搜索快照，同一职位只占一行，重复命中只增加来源与命中计数，不重复创建职位。
- 详情采集器扫描既有 `boss-details*.jsonl`，已成功采集的 `security_id` 不会再次请求；被中断的搜索任务按“关键词 + 薪资档 + 页码”续跑，已成功的切片会跳过。

## OpenCLI 空白标签问题与待办

### 根因与证据

- 根因已由真实 Chrome 页签、扩展/CLI 版本和 CLI session inventory 交叉确认：旧版 1.8.7/扩展 1.0.33 在最后一个 automation lease 释放时留下 `about:blank` 占位页；并发 ephemeral 会话会让它更频繁出现。
- 采集器还有一条独立放大路径：外层 60 秒定时器向 OpenCLI 发 SIGTERM，绕过 OpenCLI 的 lease/tab 清理。两个采集脚本现设置 `OPENCLI_BROWSER_COMMAND_TIMEOUT=180`，移除了外层强杀，并在子进程设置 `OPENCLI_CLOSE_OWNED_TAB=1`。
- 批次运行时，新建的 adapter 标签在首次导航前可能短暂显示 `about:blank`；这只是加载中的起始页。必须等采集进程退出再判断是否残留。最终 27 条队列运行完、采集进程退出后检查 Chrome，全局标签清单无空白页；这是当前链路的实际采集验证。
- 详情漏采是另一条独立根因：BOSS adapter 的 DOM 解析器未识别多种页面结构。HTTP 200 的保留 HTML 中含有真实职责、要求和公司字段，但 adapter 将部分响应报成 `AUTH_REQUIRED` 或“不完整职位”；新增本地 HTML 解析回退与离线恢复工具后已恢复。
- 其中两种页面形态已解析：完整职责/要求文本；只给短摘要的页面。后者标记为 `short-summary`，不补造任职要求。解析器不会保留招聘者姓名或联系方式。

### 可证伪假设

1. 上游扩展的最后租约释放会把标签页导航到 `about:blank`。预测：使用上游版本打开并关闭一个新会话会留下空白占位；修复版在借用的用户窗口关闭该标签页。
2. ephemeral 会话/并发放大残留数量。预测：并发越高空白标签越多，复用单个持久会话则减少；此假设只能解释频率，不能解释单个会话为何留下空白。
3. 守护进程租约状态不一致导致孤儿页。预测：如果是主因，清零租约并更换扩展后仍会持续出现；如修复后不再产生，则该假设降级。

## 后续采集与分析

详情采集完成后继续分析，至少区分：

1. 岗位硬条件：深圳、整段月薪区间 20–40K、经验区间上限不超过 5 年、招聘主体、岗位是否仍有效。

所有筛选和排序结论应保留证据链接；即使本轮所有查询切片均成功，也不等于深圳招聘岗位的市场普查，样本边界仅限本轮关键词、薪资档、账号可见结果和采集时间。
