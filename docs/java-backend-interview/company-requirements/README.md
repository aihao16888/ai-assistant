# 公司招聘要求库

> 当前状态：初始目录，待持续收录。

## 1. 用途

集中保存不同公司的岗位要求。每家公司、每个岗位单独建立文档，避免多个岗位的招聘要求混在一起。

## 2. 单个岗位文档必须包含

1. 公司名称、岗位名称、资料收录日期。
2. 招聘发布日期；如果来源没有提供，明确写“未提供”。
3. 岗位职责原文。
4. 任职要求原文。
5. 招聘页面明确列出的技术标签。
6. 明确要求与加分项的区分。
7. 我们对岗位能力的分析，必须与招聘原文分开。

## 4. 后续收录规则

- 文件名采用“岗位名称.md”，同一公司有多个岗位时在公司目录内分别建立。
- 原文尽量忠实保留，不因排版而改变语义。
- 不擅自补充薪资、地点、学历、年限或招聘发布时间。
- 如果岗位要求更新，记录版本日期，不覆盖旧版本的历史事实。
- 分析推断统一放在“岗位分析”章节，不能混入“招聘原文”。
