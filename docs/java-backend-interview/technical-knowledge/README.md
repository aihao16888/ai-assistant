# 技术知识库

> 每个知识点都必须“解释清楚”，不能只留下学习目标或验收口号。  
> 当前版本：v0.1，待用户审计。

## 1. 学习结构

技术知识分为两层：

- **项目型知识**：解释技术如何解决 DMS 中的真实业务问题。
- **通用基础知识**：解释技术本身的概念、原理、边界和常见面试问题。

项目型知识帮助讲出实践经历；通用知识帮助回答面试官从项目继续向底层追问的问题。

## 4. 每个知识点的阅读方法

建议按以下顺序学习，而不是先背面试答案：

1. 先理解“它解决什么问题”。
2. 再理解内部机制和执行流程。
3. 对照 DMS 的业务场景，判断是否真正使用了该机制。
4. 阅读失败场景：并发、超时、宕机、重复、数据不一致。
5. 最后练习面试回答和追问。

## 5. 本知识库的审计要求

- 术语准确，不把锁、缓存、幂等、事务等概念混为一谈。

- 项目映射必须标明已确认或待核实。
- 标准答案不能超出用户实际经历。
- 验收标准必须能检验前文解释的知识，而不是抽象口号。
