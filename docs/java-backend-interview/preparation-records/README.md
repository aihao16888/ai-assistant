# 岗位专项准备与面试复盘

> 用途：每次面试都建立独立记录，不复制整份通用知识库，而是引用公司要求和个人素材。

## 1. 单家公司专项准备应包含

1. 公司、岗位、收录日期、招聘版本。
2. 招聘要求摘要和原文链接。
3. 每条要求与个人经历的匹配情况。
4. 重点知识差距及优先级。
5. 项目故事选择与表达稿。
6. 技术问题清单和学习进度。
7. 模拟面试问题、自己的回答和纠错。
8. 实际面试反馈、未回答问题和后续补强计划。

## 2. 匹配状态

| 状态 | 含义 |
|---|---|
| 已匹配 | 有真实项目经历或可核验实践 |
| 部分匹配 | 接触过，但原理、深度或证据不足 |
| 待补基础 | 尚无项目实践，需要先建立概念理解 |
| 未匹配 | 当前没有相关经验，不应包装成已掌握 |
| 待确认 | 个人经历或招聘要求还需要核实 |

## 4. 面试结束后必须记录

- 面试官实际问了什么？
- 哪些问题回答不准确或不完整？
- 哪些追问暴露了知识盲区？
- 哪些项目描述缺少证据？
- 哪些要求与原先分析不同？
- 下一轮准备应该调整什么？

面试复盘的目标是更新个人素材库和通用技术知识库，而不是只把题目记下来。
