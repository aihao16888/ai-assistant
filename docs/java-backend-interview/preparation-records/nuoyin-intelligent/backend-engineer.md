## 1. 本轮准备目标

目标不是把 JD 中每个技术名词都包装成项目经验，而是：

1. 找出与三年 Java 后端经历匹配的要求；
2. 选出最有说服力的真实 DMS 项目故事；
3. 把项目中已经使用但理解不深的技术补到能够应对追问；
4. 对没有实践过的技术建立必要的概念认知；
5. 形成一份可以在下一家公司复用的准备资产。

## 3. 本轮重点项目故事

### 故事 1：安全编码生成与 Redis 并发控制

优先级：P0。

要讲清楚：
- 为什么安全编码必须全局唯一；
- 组织、车型、年月、序号分别代表什么；
- 序列命名空间如何定义；
- 为什么一次生成 20–50 个编号会产生竞争；
- Java 本地锁与 Redis 分布式锁分别解决什么问题；
- Redis 缓存、INCR/INCRBY 和数据库序号表如何协作；
- 锁过期、服务宕机、缓存丢失、数据库回写失败时怎么办；
- 数据库唯一约束是否作为最后防线。

参考材料：[Redis 缓存、分布式锁与唯一序号](../../technical-knowledge/redis/cache-lock-counter-and-uniqueness.md)

### 故事 2：Redis 防止重复受控发布

优先级：P0。

要讲清楚：
- 重复提交的业务后果；
- Key 的业务维度；
- SET NX 的原子性；
- TTL 设计；
- 首次提交失败后如何释放或恢复；
- Redis 防重和数据库幂等如何配合。

参考材料同上，并结合 DMS 项目素材核实实际实现。

### 故事 3：RabbitMQ 同步 OA 审批节点

优先级：P0。

要讲清楚：
- OA 流程引擎在什么节点产生消息；
- 谁是生产者，谁是消费者；
- Exchange、Queue、Routing Key 如何配置；
- DMS 如何判断目标审批节点；
- 第三方同步成功、超时、失败时如何处理；
- 重复消息如何避免重复副作用。

参考材料：[RabbitMQ 与 OA 审批节点同步](../../technical-knowledge/messaging/rabbitmq-and-oa-approval-sync.md)

### 故事 4：数据库类型映射与 SQL 查询

优先级：P0。

要讲清楚：
- 数据库列类型和 Java 属性类型；
- MyBatis/JDBC 参数绑定；
- 隐式转换；
- 索引是否使用；
- EXPLAIN 如何验证；
- 调整类型后如何回归测试。

参考材料：[MySQL、PostgreSQL 与 SQL 性能优化](../../technical-knowledge/database/mysql-postgresql-and-sql-performance.md)

### 故事 5：三台服务器与分布式部署

优先级：P0。

要讲清楚：
- 三台机器分别运行什么；
- 是同一服务多实例还是多个独立服务；
- 请求如何分发；
- 数据库在哪里，多个实例如何访问；
- Redis 锁为什么跨实例有效；
- 数据库如何通过事务和约束保护数据；
- 单个应用节点或数据库故障会发生什么。

参考材料：[微服务、多实例部署与数据一致性](../../technical-knowledge/microservices/distributed-deployment-and-data-consistency.md)

## 5. 第一轮模拟面试题

### 项目与架构
1. 请介绍你负责的文档管理系统模块。
2. 文档受控发布的完整业务流程是什么？
3. OA 审批流程如何同步到 DMS？
4. DMS 为什么要在某些审批节点向第三方同步？
5. 你们三台服务器分别部署什么？如何实现高可用？

### Java 与并发
6. synchronized 和 ReentrantLock 有什么区别？
7. 为什么本地锁无法解决多实例并发？
8. 什么是竞态条件？如何用编号生成案例解释？
9. 线程池的核心参数分别是什么？如何避免任务堆积？

### Redis
10. Redis 为什么适合做缓存？
11. SET NX PX 如何实现分布式锁？
12. 为什么释放锁需要 Token 校验？
13. 锁过期但旧线程还在执行怎么办？
14. INCR 为什么是原子操作？
15. Redis 计数器和数据库序号表如何保持一致？
16. Redis 防重与业务幂等有什么区别？

### 数据库
17. B-tree 索引如何帮助查询？
18. 联合索引的字段顺序为什么重要？
19. 如何分析一条慢 SQL？
20. MySQL 与 PostgreSQL 的事务隔离有什么区别？
21. 数据库字段是 Long，Java 参数是 String，可能有什么问题？
22. 如何证明查询是否使用了索引？

### RabbitMQ
23. Exchange、Queue、Binding 分别是什么？
24. Publisher Confirm 和 Consumer ACK 有什么区别？
25. 消息重复消费怎么处理？
26. 第三方系统超时，如何保证消息不丢且不重复执行业务？
27. 消息积压如何定位？

### 工程与运维
28. Linux 如何根据请求时间和关键字定位异常日志？
29. Git 如何处理多人协作中的分支冲突？
30. 单元测试如何覆盖 Redis 防重或编号生成的并发边界？

以上是第一轮题库，不代表真实面试题。
